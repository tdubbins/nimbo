# Nimbo

A two-player card game you play online in the browser.

One player creates a game and gets a four-character code, the other joins with that code. The connection
runs directly between the two devices, so there's no server to set up. There's also a chat, a running
scoreboard, and a sky that changes with the time of day.

## How to play

Both players need a copy of `index.html` on their own laptop or desktop computer. Download the file,
then open it in your browser by double-clicking it. Everything lives in that one file, nothing to
install.

Nimbo doesn't work on phones or tablets at the moment, so make sure you're both on a computer.

If a page gets reloaded by accident during a game, you can simply pick up where you left off.

## Note

Nimbo is inspired by well-known card games, but it's an independent hobby project with no affiliation
to any game publisher.
